# Value before the loop

| Procedure | Value |
|---|---|
| Declare | make a decision explicit |
| Tag | make state discoverable |
| Observe | reveal signals and anomalies |
| Normalize | make unlike units comparable |
| Aggregate | create a portfolio or workboard view |
| Project | make state visible |
| Transmit | reduce repeated AI explanations |
| Journal | prove that synchronization occurred |

```text
one procedure produces information
        ↓
another makes it comparable
        ↓
another makes it visible
        ↓
another passes it to the next human or agent
```
