# Origins and foundations

This project began with a practical context-drift problem: work existed in
files, knowledge articles, status records, dashboards, and AI sessions, but no
small team could reliably see the same current state.

## Conceptual references

- Edwin Hutchins, *Cognition in the Wild* (MIT Press, 1995), anchors the idea
  that cognition is distributed across people, artifacts, and procedures.
- Ikujiro Nonaka and Hirotaka Takeuchi, *The Knowledge-Creating Company*
  (Oxford University Press, 1995), anchors the movement between tacit and
  explicit organizational knowledge.
- W3C PROV provides a model for connecting entities, activities, and agents so
  that generated information retains provenance.

These references give vocabulary and design questions. They do not certify this
repository as an academic theory or validate every implementation choice.

## Local lineage, generalized

The private setup that inspired this work separated authority, knowledge,
observation, projection, orchestration, and scheduling. This repository keeps
those roles but renames the examples as MyCollabIA and MyKnowledgeBase.
